# Inverno - Web Page Project

Pagina web statica realizzata per esercitare struttura semantica e stile CSS moderno

## Descrizione

Inverno è una pagina web minimalista sviluppata per consolidare competenze front‑end attraverso l’uso di HTML semantico, CSS moderno e una struttura pulita e leggibile.
Il progetto è stato realizzato con il supporto dell’AI per ottimizzare contenuti, organizzazione e coerenza stilistica.

## Tecnologie e tecniche utilizzate
- HTML5 — struttura semantica (header, main, section, footer)
- CSS3 — stile essenziale, palette coerente, layout responsive
- AI Assistance — supporto nella revisione, ottimizzazione e organizzazione del progetto
- Best practice — codice ordinato, classi chiare, gerarchia tipografica curata
